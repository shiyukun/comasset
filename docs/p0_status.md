# P0 Status

Date: 2026-06-30

This document tracks the completed core P0 items plus the two follow-on data and simulation items. Other ideas stay in backlog until explicitly pulled forward.

## 1. Real Data Sources

Status: implemented for P0.

- Prices: `data/live_prices.json`, generated by `scripts/fetch_prices_yahoo.js`; covers current U.S. and Singapore-listed candidates.
- Fundamentals: `data/live_fundamentals.json`, generated by `scripts/fetch_fundamentals_sec.js`; covers U.S. stocks through SEC companyfacts. Singapore stocks use manual baseline metrics until SGX/company-announcement financial ingestion is added.
- ETF/fund holdings: `data/live_holdings.json`, generated by `scripts/fetch_holdings_official.js`.
- Macro: `data/live_macro.json`, generated by `scripts/fetch_macro_fred.js`.
- Data source manifest: `config/data_sources.json`.

Current limitation: Singapore company fundamentals are not yet automated. News/event classification is monitoring input and does not directly raise recommendation confidence.

## 5. Family Members and Permissions

Status: implemented for P0 local use.

- Role and permission config: `config/app_config.json` and `web/config.js`.
- UI member switcher: `web/index.html`.
- Permission enforcement: `web/app.js`.
- Validation script: `scripts/validate_family_access.js`.

P0 behavior:

- `admin`: view research, edit family notes, switch member context, and run the manual weekly pipeline.
- `reviewer`: view research, edit their own notes, and switch member context.
- `viewer`: view research and switch member context only.
- Notes are stored per member in browser `localStorage`.
- Local audit log records member switches and note saves in browser `localStorage`.

This is not backend authentication. It is a local access model for a static, family-internal MVP.

## 6. Real News and Events

Status: implemented.

- Fetch script: `scripts/fetch_news_events.js`.
- Stored data: `data/live_news_events.json`.
- Sources: Yahoo Finance ticker-specific RSS for all candidates and SEC EDGAR submissions for U.S. stock events.
- Coverage: current 9/9 recommendation candidates.
- Snapshot field: `recommendations[].newsEvents`.

Every item keeps the headline, publisher, source URL, publish time, category, impact, confidence, and decision-pressure score. Headlines are monitoring evidence only and do not directly create buy/DCA labels.

## 7. Historical Snapshot Backtest

Status: implemented with a short-history warning.

- Shared engine: `web/backtest_engine.js`.
- Browser input bundle: `web/backtest_data.js`.
- CLI runner: `scripts/run_snapshot_backtest.js`.
- Filesystem run history: `data/simulation_runs/`.
- Interactive family runs: browser `localStorage`, isolated by member in the UI.

The engine only uses a snapshot when `snapshot.generatedAt` is earlier than the simulated trade date. It reads real historical prices, applies configurable monthly/quarterly rebalancing and slippage, converts SGD holdings with `SGDUSD=X`, and saves the exact snapshot IDs used. Current results are not statistically meaningful because only two historical weekly snapshots exist; reliability grows as weekly snapshots accumulate.

## 8. Scheduled and On-demand Refresh

Status: implemented for the local service.

- Local server: `server/comasset_server.js`.
- Scheduler config: `config/refresh_schedule.json`.
- Refresh orchestrator: `scripts/refresh_pipeline.js`.
- Semantic input fingerprints prevent duplicate scoring and snapshots when only retrieval timestamps change.
- Recommendation and watchlist buttons invoke the refresh API and poll the audited run record.
- Changed recommendation inputs produce a unique snapshot; changed watchlist inputs rebuild the horizon analysis.
- Codex auto-audit is attempted after changed recommendation scoring. A failed or unavailable Codex call does not block the deterministic snapshot and is disclosed as pending review.

The scheduler runs only while the local Node service is running. S3 static hosting cannot execute these jobs; AWS deployment requires a compute service such as Lambda/ECS plus authenticated API routing.
