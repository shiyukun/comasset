# 美股、新加坡股票与基金投资预测网站 PRD

版本：v0.1  
日期：2026-05-30  
产品代号：待定  
目标用户：家庭内部少量个人用户  
目标市场：以美国股票、新加坡股票、ETF、共同基金为核心的自用投资研究工具

## 1. 产品概述

本产品是一个面向家庭内部少量个人用户的美股、新加坡股票与基金投资研究网站，帮助用户发现潜在的短期、长期和超长期投资机会，理解每个建议背后的核心影响因素，并通过基于真实历史数据的虚拟演练观察策略表现。

产品定位不是“保证收益”的自动投顾，而是“家庭内部自用的数据驱动投资研究、解释和模拟平台”。系统输出应始终包含置信度、风险提示、关键假设和回测限制，避免将模型预测包装成确定性建议。

参考：https://www.morningstar.co.uk/uk/xray/overview

## 3. 用户与场景

### 3.1 目标用户

1. 家庭内部投资决策者：希望用统一工具跟踪美股、新加坡股票、ETF、共同基金机会，并理解系统为什么给出建议。
2. 长期配置使用者：关注基本面、估值、增长质量、分红、费用率和资产配置。
3. 短期观察使用者：关注动量、技术指标、新闻事件、财报、市场情绪和风险控制。
4. 策略验证使用者：希望验证某个策略在历史数据中的表现。

### 3.2 核心使用场景

1. 用户每周打开网站，查看由工具分析产出的短期、长期和超长期推荐列表。
2. 用户点开某个标的，查看推荐理由、影响因素、风险项、历史表现和相似标的。
3. 用户设定“初始资金 10,000 美元，每月按系统建议投资”，运行虚拟演练并查看收益曲线。
4. 用户对比系统策略与 SPY、QQQ、VTI、现金持有等基准的表现。

## 4. 产品目标

### 4.1 MVP 目标

1. 提供美股、新加坡股票、ETF、共同基金的短期、长期和超长期推荐列表。
2. 每个推荐必须给出推荐方向、持有周期、原因、关键指标、风险和置信度。
3. 提供影响标的表现的参数分析，包括基本面、技术面、宏观、情绪和基金特有指标。
4. 提供基于历史真实价格数据的虚拟演练：初始 10,000 美元，每月根据系统建议执行投资。
5. 输出策略与 SPY 或用户选择基准的收益、回撤、波动率对比。

### 4.2 非目标

1. MVP 不直接连接券商下单。
2. MVP 不提供个性化注册投资顾问服务。
3. MVP 不承诺收益，不使用“稳赚”“保证盈利”等表达。
4. MVP 不覆盖期权、期货、加密货币和外汇。
5. MVP 不做公开获客、订阅付费或社区增长。

## 5. 信息架构

### 5.1 首页 / Dashboard

首页直接进入投资研究工作台，不做营销落地页。

核心模块：
1. 本周推荐概览：短期买入、长期买入、超长期买入。
2. 市场状态：指数表现、VIX、利率、美元指数、行业热度。
3. 策略演练摘要：最近一次虚拟组合收益、最大回撤、相对基准超额收益。
4. 风险提醒：财报密集期、宏观数据、组合集中风险。

### 5.2 推荐列表

列表由工具基于数据、模型评分和 Codex Public Equity Investing skill 分析后自动产出，不是人工手动维护的静态清单。

列表分为三个 Tab：
1. 短期投资：适合 1 天至 3 个月持有的股票、ETF、共同基金。
2. 长期投资：适合 6 个月至 2 年持有的股票、ETF、共同基金。
3. 超长期投资：适合 2 年以上持有的股票、ETF、共同基金。

列表字段：
1. Ticker / 名称 / 类型。
2. 推荐方向：买入、持有观察、回避。
3. 推荐周期：短期、长期、超长期。
4. 综合评分：0-100。
5. 置信度：低、中、高。
6. 预期收益区间。
7. 主要原因 Top 3。
8. 主要风险 Top 3。
9. 最近更新时间。
10. 数据质量状态。

更新频率：
1. 推荐列表每周更新一次。
2. 行情和新闻数据可以更高频刷新，但不会自动改变本周推荐结论。
3. 若出现重大财报、监管、宏观或基金经理变更事件，系统可以标记“需复核”，但下次正式推荐仍按每周节奏生成。

#### 自选分析与推荐列表的边界

1. 家庭成员可指定股票或基金进入独立“自选分析”视图，首批包括 GRAB、SPCX（SpaceX）和 AIQ。
2. 自选标的读取真实行情、新闻/SEC 事件、官方来源及可用的 ETF/基金持仓数据，并展示研究摘要、重点观察、风险、证据缺口和下一步研究。
3. 自选标的不参与推荐评分、Top Ideas 排名或历史 snapshot 回测选股，除非后续经过正式候选池评审并明确迁移。
4. 自选分析支持刷新已生成的数据文件；刷新不会改变正式周度推荐结论。
5. 每个自选标的必须提供未来半年、未来一年和两年以上三个期限的屏幕级研究动作，动作限定为买进、持有或卖出。
6. 每个期限动作必须同时展示置信度、核心理由、转为更积极的触发条件和转为更谨慎的触发条件，并显示分析截止日期。
7. 自选期限动作只用于家庭内部研究，不是针对个人账户、成本基础或风险承受能力的交易指令。

### 5.3 标的详情页

详情页结构：
1. 概览：价格、涨跌幅、市值、资产类型、评分、建议动作。
2. 推荐理由：用自然语言说明为什么进入列表。
3. 因子拆解：展示基本面、估值、成长、盈利质量、动量、技术面、情绪、宏观敏感度、基金指标。
4. 风险分析：估值风险、基本面恶化、流动性、行业集中、财报事件、宏观事件。
5. 历史表现：收益曲线、最大回撤、与基准比较。
6. 新闻与事件：财报、分红、拆股、评级变化、宏观事件。
7. 相似标的：同板块股票、同类型 ETF/基金。
8. 解释日志：本次评分相较上次变化的主要原因。

### 5.4 分析页

分析页聚焦“哪些参数影响股票和基金”。

模块：
1. 全市场因子热力图。
2. 行业轮动分析。
3. 宏观参数影响：利率、通胀、美元、油价、就业、GDP、VIX。
4. 标的因子贡献：查看某只股票/基金为什么被推荐或被降级。
5. 参数教育说明：解释 P/E、EPS Revision、Momentum、Sharpe、Expense Ratio 等指标含义。

### 5.5 虚拟演练页

用户可选择：
1. 初始资金：默认 10,000 美元。
2. 每月投入：默认 0，可设置固定金额。
3. 策略来源：系统短期建议、系统长期建议、系统超长期建议、短期+长期混合、自定义组合。
4. 调仓频率：每月、每季度、每半年。
5. 最大单一标的权重。
6. 交易费用、滑点、税费假设。
7. 基准：SPY、QQQ、VTI、60/40 组合、现金。

输出：
1. 最终资产价值。
2. 总收益率、年化收益率。
3. 最大回撤。
4. 波动率、Sharpe、Sortino。
5. 胜率、月度收益分布。
6. 与基准对比。
7. 每月交易记录。
8. 当前持仓与历史持仓变化。
9. 免责声明：回测存在幸存者偏差、未来函数、数据质量、税费和流动性假设限制。

## 6. 功能需求

### 6.1 推荐引擎

#### 长期投资推荐

适用标的：
1. 美股普通股。
2. 新加坡交易所股票。
3. ETF。
4. 共同基金。

核心因子：
1. 基本面：收入增长、利润增长、现金流、ROE、毛利率、负债率。
2. 估值：P/E、Forward P/E、P/S、EV/EBITDA、PEG、相对历史估值。
3. 盈利质量：自由现金流、利润稳定性、会计质量。
4. 分析师预期：EPS 修正、目标价变化、评级共识。
5. 基金指标：费用率、AUM、跟踪误差、换手率、历史风险调整收益、底层持仓集中度。
6. 风险：最大回撤、波动率、行业集中、利率敏感度。

输出要求：
1. 推荐等级：强烈关注、关注、中性、回避。
2. 建议持有周期：6-24 个月。
3. 入选原因必须可解释，至少 3 条。
4. 必须列出不确定性和反向证据。

#### 短期投资推荐

适用标的：
1. 流动性高的美股和新加坡股票。
2. ETF。

核心因子：
1. 动量：1 周、1 月、3 月价格动量。
2. 技术指标：均线、RSI、MACD、成交量异常、突破/跌破。
3. 事件：财报、产品发布、监管、并购、宏观数据。
4. 市场情绪：新闻情绪、社交媒体热度、分析师短期修正。
5. 风险控制：ATR、止损距离、流动性、空头拥挤度。

输出要求：
1. 推荐动作：短期买入、观察、止盈、止损。
2. 建议持有周期：1 天至 3 个月。
3. 目标区间和止损区间。
4. 触发条件，例如“收盘价站上 20 日均线且成交量放大”。

#### 超长期投资推荐

适用标的：
1. 具备长期竞争优势、稳定现金流或结构性增长机会的美股或新加坡普通股。
2. 低费用、规模稳定、跟踪误差可控的 ETF。
3. 费用、基金经理、历史风险调整收益和底层持仓质量可解释的共同基金。

核心因子：
1. 长期复利能力：收入、利润、自由现金流和 ROIC 的多年趋势。
2. 护城河与行业地位：市场份额、品牌、网络效应、成本优势或监管壁垒。
3. 估值安全边际：相对历史估值、同业估值和长期增长预期的匹配度。
4. 资产配置价值：与现有持仓的相关性、行业/地区/资产类别分散效果。
5. 基金质量：费用率、换手率、管理团队稳定性、持仓透明度和风格一致性。
6. 长期风险：技术替代、监管变化、行业周期、集中度和回撤承受能力。

输出要求：
1. 推荐动作：超长期买入、定投观察、持有观察、回避。
2. 建议持有周期：2 年以上。
3. 必须说明适合长期持有或定投的核心逻辑。
4. 必须列出可能破坏长期逻辑的反向证据和退出条件。

### 6.2 分析参数体系

股票参数：
1. 价格与收益：历史收益率、相对强弱、波动率、Beta。
2. 基本面：收入、EPS、毛利率、净利率、现金流、负债。
3. 估值：P/E、Forward P/E、P/S、P/B、EV/EBITDA。
4. 成长：收入增长、EPS 增长、预期增长。
5. 盈利质量：ROIC、ROE、FCF Margin。
6. 技术面：均线、RSI、MACD、布林带、成交量。
7. 情绪：新闻情绪、分析师评级、机构持仓、内部人交易。
8. 事件：财报日、分红日、宏观公布日。

基金/ETF 参数：
1. 费用率。
2. AUM 与流动性。
3. 跟踪误差。
4. 分红率。
5. 历史收益与最大回撤。
6. Sharpe、Sortino。
7. 行业、地区、资产类别暴露。
8. 前十大持仓和集中度。
9. 与用户已有持仓的重叠度。

宏观参数：
1. 美债收益率。
2. Fed 利率预期。
3. CPI / PCE。
4. 非农就业。
5. 美元指数。
6. 油价。
7. VIX。
8. 行业 ETF 资金流。

### 6.3 虚拟演练引擎

MVP 规则：
1. 使用历史收盘价和复权价格。
2. 每月第一个交易日读取上月末系统建议。
3. 选取评分最高的 N 个标的。
4. 默认等权配置，也支持按评分加权。
5. 默认最大单一标的权重 20%。
6. 默认不使用杠杆。
7. 默认交易费用 0，滑点 0.05%，税费暂不计入但必须披露。

交易逻辑：
1. 初始 10,000 美元。
2. 每月调仓一次。
3. 若标的从推荐列表中移除，则下次调仓卖出。
4. 若短期策略触发止损，则在下一交易日收盘价退出。
5. 现金未投资部分按 0% 或可配置货币基金收益率计算。

必须避免：
1. 使用未来数据做历史决策。
2. 只展示盈利案例。
3. 忽略已退市标的造成幸存者偏差。
4. 将回测收益描述为真实可获得收益。

## 7. 数据需求

### 7.1 数据源

MVP 可选数据源：
1. 价格数据：Polygon、IEX Cloud、Tiingo、Alpha Vantage、Yahoo Finance 作为原型数据。
2. 财务数据：Financial Modeling Prep、Polygon、FactSet/Refinitiv 等后续高质量数据源。
3. ETF/基金数据：Morningstar、ETF.com、基金公司公开数据、SEC filings。
4. 新闻数据：Benzinga、NewsAPI、Finnhub、SEC EDGAR。
5. 宏观数据：FRED、Treasury、BLS、BEA。

### 7.2 数据质量要求

1. 每条推荐显示数据更新时间。
2. 标记缺失数据、延迟数据和异常数据。
3. 所有评分保存历史快照，支持回测复现。
4. 价格数据使用复权数据处理分红和拆股。
5. 模型版本必须记录，避免回测结果无法追踪。
6. 每周推荐结果必须保存快照，用于虚拟演练和事后复盘。

## 8. 模型与评分

### 8.1 综合评分

建议采用 0-100 分：
1. 基本面 25%。
2. 估值 15%。
3. 成长 15%。
4. 动量/技术 15%。
5. 情绪/事件 10%。
6. 风险控制 10%。
7. 基金特有指标或持仓质量 10%。

股票和基金应使用不同评分模板，不能用同一套指标强行比较。

### 8.2 Codex Public Equity Investing Skill 要求

股票、ETF 和共同基金的分析必须接入 Codex 的 Public Equity Investing skill，作为标的分析、新闻/财报摘要、风险识别和推荐理由生成的重要分析层。

使用要求：
1. Codex Public Equity Investing skill 的输出必须和结构化行情、财务、基金持仓、宏观数据一起进入评分流程。
2. Codex Public Equity Investing skill 负责生成可读解释，但最终评分和推荐标签必须由本系统的规则、数据快照和模型版本共同决定。
3. 每条推荐必须保存 Codex Public Equity Investing skill 的分析摘要、使用时间、输入数据范围和 skill 版本，便于追溯。
4. 当 Codex skill 输出与结构化数据冲突时，页面必须显示冲突提示，并优先要求用户复核。
5. 不允许只基于 Codex skill 的自然语言判断生成买入建议。

### 8.3 可解释性

每次推荐必须包含：
1. 本次评分最高的正向因素。
2. 本次评分最低的负向因素。
3. 相较上次评分变化最大的因素。
4. 模型不确定性说明。
5. 可被用户验证的数据点。

### 8.4 人工与 AI 的边界

AI 可用于：
1. 汇总新闻和财报电话会。
2. 解释指标变化。
3. 生成推荐理由草稿。
4. 识别风险因子。

AI 不应单独决定：
1. 最终买入/回避标签。
2. 高风险标的推荐。
3. 合规免责声明。

## 9. UX 要求

### 9.1 设计原则

1. 首屏是工具，不是营销页。
2. 信息密度适中，偏研究终端风格。
3. 所有推荐都要能点开看理由。
4. 重要风险与收益并列展示。
5. 避免只用绿色/红色表达好坏，兼顾色盲用户。
6. 界面和主要解释内容必须支持中英文双语切换。

### 9.2 关键交互

1. 推荐列表支持筛选：类型、行业、市值、风险、周期、评分。
2. 推荐列表支持排序：评分、预期收益、风险、更新时间。
3. 用户可收藏标的并设置价格/评分提醒。
4. 虚拟演练支持保存参数方案。
5. 回测图表可切换收益曲线、回撤曲线、月度收益热力图。
6. 家庭成员可在本地切换成员角色，并根据角色控制备注编辑权限。
7. 家庭备注按成员隔离保存，并保留本地操作审计日志。

## 10. 合规与风险披露

页面底部和关键操作处必须显示：

1. 本产品仅用于研究和教育目的，不构成投资、法律或税务建议。
2. 投资有风险，本金可能亏损。
3. 历史收益、回测和模型评分不代表未来表现。
4. 杠杆交易和高波动资产可能造成重大亏损；MVP 不提供杠杆或反向交易策略。
5. 用户应结合自身财务状况、风险承受能力和专业顾问建议做决策。

回测页额外披露：
1. 回测可能存在幸存者偏差。
2. 回测可能无法完全模拟流动性、滑点、税费和交易限制。
3. 模型参数可能根据历史数据优化，存在过拟合风险。

## 11. 成功指标

### 11.1 自用价值指标

1. 每周推荐列表是否按计划生成。
2. 家庭成员是否能看懂每条推荐的主要原因和风险。
3. 标的详情页是否支持家庭内部讨论和复核。
4. 收藏标的数量和提醒命中数量。
5. 虚拟演练是否能帮助比较不同策略。

### 11.2 质量指标

1. 推荐解释覆盖率：100% 推荐必须有解释。
2. 数据更新时间合规率。
3. 回测可复现率。
4. 错误数据告警响应时间。
5. 家庭内部反馈的数据或解释错误数量。

### 11.3 投资研究指标

这些指标只能用于模型评估，不可作为营销承诺：
1. 策略相对 SPY 的超额收益。
2. 最大回撤。
3. Sharpe Ratio。
4. 命中率。
5. 换手率。
6. 推荐后 1 周、1 月、3 月、12 月表现分布。
